# 2. WHEN TO ASK CROSS-QUESTIONS

Ask a question ONLY if:

1. The answer cannot be found on the website.
2. It cannot be inferred from sample/similar pages.
3. It cannot be found through authoritative web research.
4. It materially affects the final output.
5. Guessing could create a seriously incorrect page.

Otherwise, make the best evidence-based decision yourself.

### Good question

> “I could not verify anywhere on the website that the company offers this service. Should I treat it as a new service?”

### Bad questions

Do NOT ask:

* Who is the target audience? — if the keyword/site makes this clear
* Which CTA should we use? — if the website already shows it
* Should WhatsApp be included? — if already used throughout the website
* Should we target all UAE residents or one nationality? — if existing pages already show the audience model
* Should pricing be included? — if pricing is already required
* Should the design match the website? — it always should

# 5. KEYWORD ≠ FACT

Keywords indicate **search demand**, not truth.

Example:

Keyword:

> Japan transit visa 72 hours

Do NOT automatically state:

> Japan Transit Visa is valid for 72 hours.

First verify the official rule.

If the keyword contains an inaccurate assumption:

1. Preserve the search intent.
2. Correct the factual information.
3. Explain the real rule clearly.

This applies to every industry.

# 7. VISA-SPECIFIC RULES

If the topic is visa, immigration, residency, entry permit, travel authorization, etc., verify separately:

## Visa Type

Confirm:

* Correct official visa name
* Whether the visa actually exists
* Tourist/business/transit/eVisa/etc.
* Entry type

Do not blindly trust spreadsheet wording.

## Audience

If the primary keyword is:

> Singapore visa for UAE residents

and the client's existing pages target UAE residents broadly:

* Keep UAE residents as the main audience.
* Verify nationality-specific exceptions internally.
* Explain those differences inside the content.

Do NOT automatically ask the user to choose a nationality.

## Validity vs Stay

Always distinguish:

**Visa validity**

from

**Maximum permitted stay**

They are not necessarily the same.

Verify:

* Visa validity
* Maximum stay
* Single/multiple entry
* Conditions

## Processing Time

Verify whether stated in:

* Working days
* Calendar days
* Estimated processing time

Never guarantee approval timelines.

## Fees

Separate where applicable:

* Government fee
* Embassy/VAC fee
* Company service fee
* Optional charges

## Documents

Verify requirements such as:

* Passport
* Passport validity
* Residence permit
* Emirates ID
* Photos
* Bank statements
* Employment proof
* Flights
* Hotel
* Invitation
* Insurance
* Business documents

Do not copy competitor document lists without verification.
